# Selfbox：聊天记录式 AI 笔记软件

## 核心功能

- 支持 ios 和安卓双平台。
- 主要交互界面设计，请参考 docs/design/ref 几张截图
- 这并不是一个 ai chat app，用户大多数情况下，就像给微信里的文件传输助手一样，给自己发消息，支持文本、图片，发送之后消息数据会存在本地，相当于聊天式的备忘录
- 重点来了，当用户激活聊天输入框左侧的模式后，才会启动 ai 对话，此时 ai agent 会将所有的聊天记录作为 context 来进行检索和回答
- 你需要设计一套给 agent 用的 tools，允许 ai 在聊天记录中检索、查看消息或图片
- 每次触发 ai 模式时，都会将最近 n 轮对话作为历史消息传入，无论是用户发的还是 ai 发的，来保证对话的连续性
- 使用 https://pub.dev/packages/ai_sdk_dart 完成 ai api 调用，设置里允许用户配置 chat completion / responses / messages 三种 api 格式调用，允许自动从 api 中拉取模型列表，允许从模型列表中启用模型，并配置模型 input/output size，是否支持图片，是否支持思考，以及思考等级
- 注意，触发 ai 模式后，ai 在 agent 模式下会包含多步 tool call 调用，不要全部展示在 ui 界面上，只使用一个 pending 态展示最新的 tool call 即可，当 ai 输出最终的文本时，也不要流式渲染出结果，而是使用一个“正在输入文字”来表示最终文本输出状态，并且在输出完毕后再统一渲染文本
- ai agent 会主动使用类似文件系统的方式构建记忆机制，你需要为 agent 编写基于文件系统的记忆机制，比如使用 `user/{profile.md, prefer.md, xxx.md}` 来组织用户自己相关的信息，使用 `topic/a-topic.md` 来追踪关于某个话题的信息，等等等，agent 需要具备自动根据用户输入对话，自动对记忆系统中的文件进行增删改查等操作，以此来维护记忆机制，所以你还要设计文件相关的增删改查 tools，你需要约束 agent 使用 `diff_patch` 的方式对文件进行更新，而不是硬写；
- 参考截图中的底部 tab 栏设计，增加用户记忆系统浏览器，使用 md 组件渲染文件内容；
- 底部 tab 暂时只需要有：聊天、记忆、我的，三个 tab 即可
- 我对设计美观度要求很高，你需要参考 design 中的截图进行风格参考，克制而合理地使用 liquid glass 组件效果营造精致感
