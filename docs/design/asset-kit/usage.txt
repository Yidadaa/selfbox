目录与建议显示宽度：
large/：大型空状态，280–400 CSS px。
medium/：中型反馈，160–240 CSS px。
small/：小型提示，48–96 CSS px。
avatar/：默认头像，32–128 CSS px；使用 contain 防止圆形裁切切掉耳朵。
states/：六种日常状态，160–280 CSS px。
logo/: 包含 svg 格式和 webp 格式 logo，svg 略有失真。

所有图片保留生成原始分辨率；以上大小是界面显示建议，不是三套同图缩放文件。
状态图均为静态图片，不是动画帧。保留比例，避免拉伸和水平翻转，以保持蓝耳朵在画面右侧。
推荐配色：奶白、天空蓝、青色、淡紫、少量暖黄。界面文案独立排版，不要烘焙到图片中。
表现统一为蓝白垂耳、奶白身体、深棕鼻子与眼睛、圆润体型、柔和立体质感。

已知限制：多图生成会有细微造型差异，无法保证几何级别完全一致。部分透明边缘有白边或杂点，深色背景尤其明显；此版适合设计评审及接入预览，正式上线前需进行边缘精修。

manifest.json 含语义 ID、相对路径、实际尺寸、建议显示尺寸和替代文本。
generation-prompts.json 保存每张图片的完整生成提示词。
