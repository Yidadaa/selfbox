## 设计

- 欢迎：欢迎小狗插画与一句介绍。
- 认识小懒：头像和 AI 名字，默认小懒 / Dozy；头像复用完整预制/相册选择器。
- 如何称呼你：一个输入项，配合记录插画；允许留空，稍后在资料中修改。
- 连接 AI：使用工作/唤醒插画，复用现有配置能力；支持跳过，已选模型时直接开始。
- 完成前统一保留表单草稿，完成时先保存资料与用户记忆，再持久化引导标记；失败保留当前页并重试。
